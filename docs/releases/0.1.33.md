# 网络设备巡检 0.1.33

- 新增软件内更新：登录后后台检查，系统设置可手动检查。
- 展示更新说明、下载进度；安装包通过签名验证后才允许安装。
- 巡检、配置备份或数据库维护执行期间暂缓安装，防止中断后台任务。
- 补齐 Windows 开发启动、安装包构建和 GitHub Releases 发布脚本。
- 统一前端、后端、Tauri 和 Cargo 版本号。

旧版 0.1.32 尚无内置更新功能，需要手动安装本版；安装后可检查后续版本。安装前关闭旧程序，保留原有数据目录。推荐使用 NSIS EXE，同时提供 MSI；更新清单按原安装格式提供对应安装包，同一台机器请沿用安装格式。
