# 网络设备巡检 0.1.34

- 提供重新完整构建的签名 Windows 安装包，补齐更新安装前准备接口。
- 沿用现有设备、系统设置、巡检任务、结果及配置备份的数据格式。
- 软件更新会先检查后台任务状态，下载完成并验证签名后才允许退出安装。

请沿用原有安装格式：NSIS EXE 或 MSI。安装完成后重新打开软件，重新登录即可读取原有数据。

## 0.1.33 升级限制

真实验收发现，已发布的 0.1.33 后端安装产物缺少 `/system/update/prepare` 接口。它能发现、下载并验证 0.1.34，但会在退出安装前提示“无法确认后台任务状态，已暂缓安装”，不会启动安装器。

原版 0.1.33 需要先关闭程序，手动覆盖安装本版；发布 0.1.34 无法修补旧版正在运行的后端接口。此次原版 0.1.33 应用内自动更新验收未通过，不应将检查更新、下载或签名验证成功视为完整升级成功。
