# 网络设备巡检软件开发需求文档

- 版本：V1.0
- 状态：需求确认稿
- 软件形态：Windows 图形界面客户端
- 适用厂商：华为、H3C、锐捷、Cisco

## 1. 项目目标

开发一套安装在 Windows 电脑上的网络设备巡检软件，供网络运维人员完成设备管理、批量巡检、配置备份和巡检报告导出。

软件以简单、稳定、方便使用为原则，不建设大型运维平台。

V1 需要解决以下问题：

1. 用图形界面维护设备和登录账号，不再修改 Python 脚本。
2. 一次选择多台设备进行巡检，自动执行对应厂商命令。
3. 清楚区分连接失败、登录失败、命令失败和数据解析失败。
4. 自动判断常见异常，并生成便于查看的 Excel 报告。
5. 定期保存设备配置，并可查看配置是否发生变化。

## 2. V1 功能范围

### 2.1 本期实现

- Windows 图形界面
- SQLite 本地数据库
- 华为、H3C、锐捷、Cisco 四类设备
- Excel 批量导入和导出设备
- SSH 批量巡检
- 基础运行状态检查
- 硬件和接口状态检查
- 配置备份和简单配置对比
- Excel 巡检报告
- 操作日志和失败重试

### 2.2 本期不实现

- Web 管理平台
- 多人同时使用
- 手机端
- 复杂审批和权限系统
- 实时流量监控
- 网络拓扑自动绘制
- 配置批量下发
- 短信、企业微信和钉钉告警

## 3. 运行环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10、Windows 11，64 位 |
| 部署方式 | 单机安装包 |
| 数据库 | SQLite，本地文件存储 |
| 网络条件 | 运行电脑能够通过 SSH 访问网络设备 |
| 默认协议 | SSH |
| 报告格式 | Excel `.xlsx` |

## 4. 用户界面

### 4.1 管理员登录界面

软件启动后首先显示管理员登录界面。管理员输入用户名和密码，验证成功后进入软件主界面。

![管理员登录界面参考图](./images/admin-login.png)

界面与功能要求：

- 包含用户名、密码输入框和登录按钮。
- 密码输入内容以掩码显示。
- 用户名或密码为空时提示用户补充，不执行登录。
- 登录失败时显示明确提示，但不说明用户名或密码哪一项错误。
- 连续登录失败 5 次后锁定 5 分钟，防止反复尝试。
- 登录成功后记录登录时间，并进入首页。
- 管理员密码加密保存，不得以明文写入数据库或日志。
- V1 只设置一个本地管理员账号，不实现多用户和复杂权限管理。

### 4.2 主界面

软件主界面采用左侧菜单，包含以下页面：

1. **首页**：显示设备数量、最近巡检结果、异常数量和最近任务。
2. **设备管理**：新增、编辑、删除、导入和筛选设备。
3. **巡检任务**：选择设备、选择检查项、启动巡检并查看进度。
4. **巡检结果**：查看设备结果、异常详情和原始命令输出。
5. **配置备份**：执行备份、查看备份记录和配置差异。
6. **系统设置**：设置并发数、超时时间、报告目录和备份目录。
7. **运行日志**：查看连接、登录、命令和程序错误。

界面要求：

- 主要操作使用明确的按钮和图标。
- 任务执行时显示总数、已完成数、成功数和失败数。
- 正常、警告、严重和失败状态使用不同颜色。
- 表格支持搜索、筛选、排序和分页。
- 耗时操作不得导致界面卡死。

## 5. 设备管理

### 5.1 设备字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 设备名称 | 否 | 可由巡检自动获取 |
| 管理 IP | 是 | IPv4 地址 |
| 厂商 | 是 | 华为、H3C、锐捷、Cisco |
| 设备类型 | 是 | 交换机或路由器 |
| SSH 端口 | 是 | 默认 22 |
| 用户名 | 是 | 设备登录账号 |
| 密码 | 是 | 加密保存，不在界面明文显示 |
| Enable/Super 密码 | 否 | 设备需要提权时使用 |
| 分组 | 否 | 例如核心、汇聚、接入、机房 |
| 备注 | 否 | 自定义说明 |

### 5.2 功能要求

- 支持单台新增、编辑和删除。
- 支持 Excel 批量导入和导出。
- 导入时校验 IP、厂商、用户名和密码。
- 导入错误时显示具体行号和错误原因。
- 支持按厂商、分组、设备类型和关键字筛选。
- 同一管理 IP 不允许重复保存。
- 密码使用 Windows 本机加密能力或等效方式加密保存。
- 日志、报告和错误信息不得输出密码。

## 6. 巡检任务

### 6.1 创建任务

用户可以：

1. 选择全部设备、设备分组或指定设备。
2. 选择快速巡检或完整巡检。
3. 设置任务名称。
4. 点击“开始巡检”。

任务启动后，软件按设置的并发数同时处理多台设备，默认并发数为 10。

### 6.2 任务状态

任务状态包括：

- 等待执行
- 正在执行
- 已完成
- 部分失败
- 执行失败
- 已取消

每台设备必须分别记录：

- 网络连接状态
- 登录认证状态
- 命令执行状态
- 数据解析状态
- 最终巡检结论

数据解析失败不得显示为巡检成功，应显示为“数据获取失败”。

### 6.3 异常处理

- 单台设备失败不得中断整个任务。
- 连接超时和临时网络错误默认重试 2 次。
- 认证失败不重复尝试，避免账号锁定。
- 每条命令可单独设置读取超时时间。
- 任务可由用户取消；已完成结果需要保留。

## 7. 巡检项目

不同厂商使用各自命令，但统一输出为相同字段。

### 7.1 快速巡检

| 检查项 | 输出内容 | 默认判断 |
|---|---|---|
| 设备信息 | 名称、型号、软件版本 | 数据能否正常获取 |
| 运行时间 | Uptime | 记录展示 |
| CPU | 当前使用率 | 大于等于 80% 为警告 |
| 内存 | 当前使用率 | 大于等于 80% 为警告 |
| 接口概览 | Up、Down、管理关闭数量 | 记录展示 |
| STP | 端口角色和状态 | 只展示，不直接把 DISCARDING 判为故障 |
| 当前告警 | 设备活动告警 | 存在严重告警时标记异常 |

### 7.2 完整巡检

完整巡检包含快速巡检，并增加：

| 检查项 | 输出内容 |
|---|---|
| 单板状态 | 单板在线和异常状态 |
| 电源状态 | 正常、异常、缺失 |
| 风扇状态 | 正常、异常、缺失 |
| 温度 | 当前温度和设备阈值 |
| 接口错误 | CRC、输入错误、输出错误和丢包 |
| 链路聚合 | 聚合组和成员口状态 |
| 邻居状态 | OSPF、BGP、VRRP，设备不使用时显示“不适用” |
| NTP | 是否同步 |
| 存储空间 | 剩余空间和使用率 |
| 配置保存状态 | 当前配置是否已保存 |

### 7.3 厂商适配

- 每个厂商建立独立命令配置和解析模板。
- 同一检查项在界面和报告中使用统一名称。
- 设备不支持某条命令时显示“不支持”，不得显示为设备故障。
- 设备未启用某种协议时显示“不适用”。
- V1 优先支持常用园区交换机和路由器；特殊型号通过增加模板扩展。

## 8. 结果判定

巡检结论分为：

| 结论 | 说明 |
|---|---|
| 正常 | 所有已执行检查项均正常 |
| 警告 | 指标达到警告阈值或存在一般异常 |
| 严重 | 硬件故障、关键邻居中断或严重告警 |
| 数据获取失败 | 命令失败、回显不完整或解析失败 |
| 连接失败 | IP 不可达或 SSH 端口无法连接 |
| 认证失败 | 用户名、密码或权限不正确 |

CPU、内存等阈值可在系统设置中修改。设备温度和光模块应优先采用设备输出的告警阈值，不使用统一固定值。

## 9. 配置备份

### 9.1 备份功能

- 支持对全部、分组或指定设备执行配置备份。
- 配置文件按厂商和设备分类保存。
- 文件名称包含设备名称、IP 和备份时间。
- 备份目录已存在时可继续使用。
- 备份失败时保留上一份有效配置。
- 检查命令报错、空内容和明显截断，异常内容不得标记为有效备份。

### 9.2 配置对比

- 新配置与上一份有效配置进行文本对比。
- 显示新增、删除和修改的配置行。
- 忽略可配置的动态内容，例如采集时间。
- 用户可打开备份文件所在目录。
- 默认每台设备保留最近 30 份备份，该数量可修改。

## 10. 巡检报告

巡检完成后可以导出 Excel 报告，包含：

1. **任务汇总**：任务名称、时间、设备总数、正常数、警告数、严重数、失败数。
2. **设备结果**：每台设备的基本信息、各项指标和最终结论。
3. **异常清单**：只列出警告、严重、连接失败、认证失败和数据获取失败。
4. **执行失败**：失败阶段、失败命令和错误原因。

报告要求：

- 文件名包含任务名称和时间，不覆盖历史文件。
- 使用颜色区分正常、警告、严重和失败。
- 汇总数字必须与设备结果明细一致。
- 报告不得包含密码。
- 软件数据库中的任务结果可以再次导出报告。

## 11. 数据库

SQLite 数据库至少保存以下内容：

- 设备信息
- 加密后的设备凭据
- 巡检任务
- 每台设备的执行状态
- 巡检结果
- 配置备份记录
- 操作日志

数据库要求：

- 软件首次启动时自动创建数据库。
- 软件升级时能够自动升级数据库结构。
- 删除设备前需要用户确认。
- 删除设备时，历史巡检和备份记录默认保留。
- 提供“备份数据库”功能，生成可恢复的数据库副本。

## 12. 日志

- 记录软件启动、设备导入、巡检开始和结束、备份开始和结束。
- 记录连接失败、认证失败、命令超时和解析失败。
- 日志包含时间、任务、设备 IP、阶段和错误信息。
- 日志文件按日期保存，默认保留 30 天。
- 日志中不得出现设备密码。

## 13. 系统设置

用户可设置：

- 最大并发数，默认 10
- 连接超时，默认 10 秒
- 命令读取超时，默认 30 秒
- 重试次数，默认 2 次
- 报告保存目录
- 配置备份目录
- 日志保留天数
- 配置备份保留份数
- CPU 和内存警告阈值

## 14. 验收标准

### 14.1 基本功能

- 软件可在 Windows 10 和 Windows 11 上安装、启动和卸载。
- 可以新增设备，并通过 Excel 成功导入四种厂商的设备。
- 可以选择多台设备启动巡检，界面实时显示进度且不假死。
- 单台设备失败不影响其他设备继续执行。
- 巡检完成后能够查看结果并导出 Excel。
- 可以执行配置备份并查看与上一版本的差异。
- 软件关闭后重新打开，设备、任务和结果仍然存在。

### 14.2 状态准确性

- 不可达设备显示“连接失败”。
- 密码错误显示“认证失败”。
- 命令超时或设备不支持命令时显示对应原因。
- 解析模板不匹配时显示“数据获取失败”，不得显示为“正常”。
- 未运行 OSPF/BGP 等功能的设备显示“不适用”，不得显示为异常。

### 14.3 数据安全

- 数据库中不能直接读取到明文密码。
- 日志和 Excel 报告中不能出现密码。
- 无效或截断的配置不能覆盖上一份有效备份。
- 数据库备份能够在同版本软件中恢复。

## 15. 开发阶段建议

| 阶段 | 开发内容 |
|---|---|
| 第一阶段 | Windows 界面、SQLite、设备管理、Excel 导入 |
| 第二阶段 | 多厂商连接、快速巡检、任务进度、日志 |
| 第三阶段 | 完整巡检、结果判定、Excel 报告 |
| 第四阶段 | 配置备份、配置对比、安装包和验收测试 |

## 16. 开发前需准备的资料

为了保证多厂商解析准确，需要提供以下脱敏资料：

1. 华为、H3C、锐捷、Cisco 各型号和软件版本清单。
2. 各厂商目标设备的巡检命令原始输出。
3. 现有设备 Excel 清单样例。
4. 期望的 Excel 巡检报告样例。

没有实际命令输出时，可以先完成软件框架和模拟数据演示，但不能保证所有型号的巡检解析准确。
